# XRpeditie

Jullie team maakt een proof of concept van een interactieve ervaring voor het UMU. Kies één van de drie opdrachten hieronder.

Welke opdracht je ook kiest, één vraag staat altijd centraal:

Wat doet de bezoeker hier als een onderzoeker?

Een onderzoeker is nieuwsgierig, stelt vragen, bedenkt wat er zou kunnen gebeuren, zoekt het uit en trekt een conclusie. Jullie ervaring laat de bezoeker minstens één van die dingen zelf doen.
